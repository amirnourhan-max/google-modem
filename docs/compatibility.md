# Compatibility

## Router

- OpenWrt با LuCI
- PassWall2
- Xray یا Sing-Box
- دسترسی SSH برای اجرای اسکریپت‌های نصب

## Android

- سورس پروژه در `android/proxy-monitor`
- خروجی آماده نصب در `releases/ProxyMonitorAndroid-v2.11.apk`
- ویجت Full و Compact
- Refresh دستی و Refresh هنگام تغییر IP

## Notes

- مقدار `expected_nodes` فقط سقف نمایش نودهای فعال در مانیتور و ویجت است؛ سرعت اینترنت را مستقیم تغییر نمی‌دهد.
- برای روتر کاربر، مقدار پیشنهادی نمایش Active Nodes برابر ۵ است.
- برای Preferred Node Count در Load Balancer، مقدار پیشنهادی ۳ است.
